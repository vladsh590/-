# Тяньгоу - Азиатское бистро

Современный веб-сайт для азиатского бистро "Тяньгоу" с неоновым дизайном в красно-черной цветовой гамме.

## 🎨 Особенности

- **Современный дизайн** - неоновые эффекты и анимации
- **Полное меню** - рамен, лапша, рисовая миска, закуски, напитки и десерты
- **Интерактивная галерея** - увеличение фотографий блюд с зумом и перетаскиванием
- **Форма бронирования** - удобное бронирование столиков
- **Интеграция с Яндекс.Еда** - прямая ссылка на заказ доставки
- **Яндекс.Карты** - интерактивная карта с местоположением
- **Адаптивный дизайн** - отлично работает на всех устройствах
- **Социальные сети** - ссылки на Telegram и ВКонтакте

## 🚀 Запуск

Просто откройте `index.html` в браузере. Сайт не требует установки зависимостей или сервера.

## 🎯 Разделы сайта

1. **Главная** - приветственный экран с описанием
2. **О нас** - информация о ресторане и его особенностях
3. **Меню** - полное меню с фотографиями, описаниями и ценами
4. **Контакты** - адрес, телефон, часы работы, карта и форма бронирования
